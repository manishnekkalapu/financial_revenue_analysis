# financial_revenue_analysis
# 📊 Financial Revenue Analysis Dashboard

## 🎯 Project Overview
End-to-end financial analysis of Microsoft Financial Sample dataset 
covering 700 rows across 5 countries, 6 products and 2 years (2013-2014).

## 🛠️ Tools Used
- **Excel** — Data cleaning and preparation
- **PostgreSQL** — Database design and SQL analysis
- **Power BI** — Interactive dashboard

## 📈 Key Metrics
| Metric | Value |
|--------|-------|
| 💰 Total Revenue | $118.73M |
| 📦 Total Profit | $16.89M |
| 🌍 Countries Analysed | 5 |
| 🏷️ Products Analysed | 6 |
| 📋 Total Rows | 700 |
| 📅 Years Covered | 2013-2014 |

## 🔍 Key Findings
- 🇺🇸 **USA** generated the highest revenue
- 🏛️ **Government** segment contributed **44%** of total sales
- 📦 **Paseo** was the top selling product with **$33M+** in sales
- 📅 **October** was the peak revenue month
- 💰 **Amarilla** had the highest profit margin
- 📊 **2014** outperformed 201
